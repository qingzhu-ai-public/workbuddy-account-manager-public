## 核心能力

### 账号管理

- **多账号批量导入** —— `.info` 文件一键解析，按 `uid` 去重（保留过期更晚那份）
- **一键切换客户端账号** —— 自动备份原登录态 + 可回滚（CodeBuddy 解密 Electron safeStorage 密文）
- **WorkBuddy × CodeBuddy 同管** —— 同一份账号库同时管理两套积分体系
- **导出 / 导入备份** —— 完整登录态 JSON，换电脑迁移一步到位

### 自动化（打开放在托盘，日常不用管）

- **自动签到（幂等）** —— 今日已签自动跳过，绝不重复领积分；也可设频率自动刷新积分
- **自动旅行挣积分** —— 让 Buddy 出门旅行，收益自动入账，并留有每日流水账本
- **自动成长中心** —— 任务自动接单 / 自动领奖、能量自动开 Buddy 盲盒；写请求每账号每日上限 **20 次**，防止重复消耗
- **只查不做的板块** —— 连登兑换 / 盲盒抽奖 / 补登卡**只查询状态、不代为操作**（这几项发出去不可逆）。有可操作项时会在成长表里标出来，你去官网「成长中心」点一下即可
- **可用性检测** —— 查积分时附带发 hi 心跳，正常回复 = 可用；也支持手动批量查询（按天缓存，不重复消耗）
- **跨模块互斥** —— 签到 / 刷新 / 旅行 / 成长各轮次不会挤在一起执行

> 频率、逐模块开关、上次·下次时间、「立即执行」都集中在「设置」里；「成长」标签页是纯进度面板（只看结果，不做操作）。

## 快速上手

1. 下载安装对应平台的安装包并启动
2. 选择 WorkBuddy 的 `auth/*.info` 目录或单个 `.info` 文件导入账号
3. 点击「更新全部」批量同步签到 + 积分 + 可用性
4. 到「设置」里打开 **自动刷新 / 自动旅行 / 自动成长**，之后的日常交给它跑
5. 需要用的时候，从列表里挑一个可用账号 → 点击「切换」

## 常见问题

**会重复领积分吗？**
不会。签到是幂等的（今日已签自动跳过）；成长中心的写请求每账号每日上限 20 次，超限即停。

**我的账号和 Token 会上传到哪里吗？**
不会。这是纯本地桌面工具，账号数据与登录态只保存在你自己的电脑上，没有云端同步。

**为什么有些成长玩法不自动执行？**
连登兑换 / 抽奖 / 补登卡一旦发出就不可逆，所以本工具只帮你**查状态并提示**，实际操请到官网「成长中心」自行完成。

**点「更新」会顺带签到吗？**
不会。「更新」只查积分/权益/连签/可用性，签到要靠手动点或定时任务，两者是分开的。

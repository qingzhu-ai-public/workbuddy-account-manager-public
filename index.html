核心能力

FEATURES / 为什么选青竹 Buddy
01
批量签到
一次跑完所有账号，按 uid 去重（保留过期更晚那份）。今日已签自动跳过，不会重复领积分。
02
可用性检测
查询接口附带发 hi 心跳：正常回复 = 可用；额度耗尽 / 过期 / 失效自动区分，状态在列表里实时标灰。
03
一键切换账号
自动解密 CodeBuddy 的 state.vscdb（Electron safeStorage）→ 备份 → 写入，全程不到 1 秒，原登录态可一键回滚。
04
WorkBuddy × CodeBuddy
同一份账号库同时管理两套体系，积分按 user.domain 动态路由 www.workbuddy.cn / www.codebuddy.cn。
05
列表 / 卡片视图
三列排序、可搜索、配置全部持久化（窗口大小、列宽、排序状态重启后还在）。
06
备份与迁移
JSON 全量导出（含登录态与签到进度）。换电脑导入即用，导出文件请妥善保管，不要外传。

01 · 数据导入
从 .info 文件夹读
直接选择 WorkBuddy 的 auth/*.info 目录，自动解析明文 JSON，按 uid 去重并保留过期时间更晚的副本。
02 · CodeBuddy 解密
Electron safeStorage 直读
从 state.vscdb + Local State 解出 v10 前缀密文（AES-128-CBC），无需输入密码即可完成切换。
03 · 切换安全网
自动备份可回滚
切换前把原登录态写进 state.settings.lastCbSwitch，需要时一键还原到切换前的状态。
04 · 离线缓存
积分 5 分钟缓存
同一账号短时间内重复查询命中本地缓存，避免触发风控；缓存键含 token 哈希，账号切换自动失效。

常见问题FAQ

安全吗？登录态会泄露吗？
登录态只在你的本机处理与存储，不会上传任何服务器。导出备份文件含明文 token，请妥善保管，不要发到群聊或公开网盘。
支持 Apple Silicon Mac 吗？
支持。macOS DMG 同时打 x64 + arm64（universal），Intel 和 M1/M2/M3/M4 都能装。
WorkBuddy 和 CodeBuddy 有什么区别？
两者共用一套积分体系（域名不同），本工具同时识别 www.workbuddy.cn 和 www.codebuddy.cn，一份账号库两套通行。
开源吗？
本仓库为产品官网与下载站，仅含介绍与安装包。源码仓库为私有。本工具以 MIT 协议发布，但作者暂不公开源码。

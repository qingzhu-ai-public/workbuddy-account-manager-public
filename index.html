Features

核心能力，一件件说清楚

为「同时管几十个 WorkBuddy / CodeBuddy 账号」的场景而生：把重复劳动压缩成一次点击。

01
批量签到
一次跑完所有账号，按 uid 去重（保留过期更晚那份）。今日已签自动跳过，不会重复领积分。
02
可用性检测
查询接口附带发 hi 心跳：正常回复 = 可用；额度耗尽 / 过期 / 失效自动区分，列表里实时标灰。
03
一键切换账号
自动解密 CodeBuddy 的 state.vscdb（Electron safeStorage）→ 备份 → 写入，全程不到 1 秒，原登录态可一键回滚。
04
WorkBuddy × CodeBuddy
同一份账号库同时管理两套体系，积分按 user.domain 动态路由两个官方域名。
05
列表 / 卡片视图
三列排序、可搜索，配置全部持久化——窗口大小、列宽、排序状态，重启后都还在。
06
备份与迁移
JSON 全量导出（含登录态与签到进度）。换电脑导入即用；导出文件请妥善保管，不要外传。

FAQ

常见问题

安全吗？登录态会泄露吗？+
登录态只在你的本机处理与存储，不会上传任何服务器。导出备份文件含明文 token，请妥善保管，不要发到群聊或公开网盘。
支持 Apple Silicon Mac 吗？+
支持。macOS DMG 同时提供 arm64 + x64 两种镜像，M1/M2/M3/M4 和 Intel 机器都能装。
WorkBuddy 和 CodeBuddy 有什么区别？+
两者共用一套积分体系（域名不同），本工具同时识别 www.workbuddy.cn 和 www.codebuddy.cn，一份账号库两套通行。
开源吗？+
本仓库为产品官网与下载站，仅含介绍与安装包；源码仓库私有。工具本身免费使用，欢迎反馈问题。
